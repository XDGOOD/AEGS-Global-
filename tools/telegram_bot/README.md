# AEGS Titan Telegram Bot — Модуль управления подписками и технической поддержки

Telegram-бот для автоматической обработки подписок, проверки статуса доступа, генерации ключей и приема обращений в службу технической поддержки транспортного протокола **AEGS v6 Titan**.

---

## Функциональные возможности

* **Управление учетной записью и статус:**
  * Проверка актуальности подписки в режиме реального времени.
  * Точный расчет оставшегося времени действия (дни, часы).
  * Параметры конфигурации, KeyID и статус синхронизации с сервером.
* **Тарифные планы и биллинг:**
  * Доступные периоды: 1 месяц (199 RUB / 100 Stars), 3 месяца (499 RUB / 250 Stars), 6 месяцев (899 RUB / 450 Stars), 12 месяцев (1499 RUB / 750 Stars).
  * Суммирование сроков при продлении без потери оставшихся дней.
  * Интеграция с Telegram Stars (XTR), банковскими картами и Sandbox-режимом.
* **Служба технической поддержки (Support Desk):**
  * Регистрация тикетов пользователей через раздел «Техническая поддержка» или команду `/support <текст>`.
  * Пересылка обращений администраторам бота с фиксацией в базе данных.
  * Ответ на обращения через команду `/reply <ID_обращения> <Текст_ответа>` с мгновенной доставкой пользователю в чат.
* **Генерация конфигурации:**
  * Формирование персонального токена авторизации и URI вида `aegs://<ip>:<port>/<token>?name=AEGS_Titan`.
  * Автоматическая генерация QR-кода для импорта конфигурации камерой мобильного приложения.
* **Фоновый мониторинг (Subscription Lifecycle Worker):**
  * Автоматическая проверка сроков действия каждые 60 секунд.
  * Отправка сервисных уведомлений за 72 часа и за 24 часа до завершения периода.
  * Приостановка маршрутизации и удаление ключа из базы сервера при истечении срока; восстановление при оплате.

## Конфигурация и запуск

### Параметры окружения:
* `BOT_TOKEN` — токен бота от @BotFather.
* `ADMIN_IDS` — список Telegram ID администраторов через запятую (например: `123456789,987654321`).
* `AEGS_SERVER_IP` — публичный IP-адрес сервера AEGS.
* `AEGIS_DB_PATH` — путь к SQLite базе данных сервера AEGS (`/app/data/aegis.db`).

### Запуск:
* **Linux / macOS:**
  ```bash
  ./tools/telegram_bot/run.sh
  ```
* **Windows:**
  ```cmd
  tools\telegram_bot\run_bot.bat
  ```
